Can you explain what a function is in Python with a simple example?

10:42 PM

DK

A function in Python is a reusable block of code that performs a specific task. It helps you organize your code, avoid repetition and make your program easier to understand.

Here's a simple example:

Python
1def greet(name):
2return f"Hello, {name}!"
3
4# Calling the function
5message = greet("Dhanush")
6print(message)
Output:
Hello, Dhanush!

Explanation:

  • def greet(name): defines a function named greet that takes one parameter name.
  • return returns a value from the function.
  • greet("Dhanush") calls the function and passes "Dhanush" as an argument.
  • The function returns "Hello, Dhanush!" which is printed.
