Concept Breakdown: Coroutine Suspension & Yield Inversion

Ref: PEP 492 / Asyncio Core

When execution reaches an await expression, the Python runtime delegates frame control via the generator-based coroutine protocol. Rather than blocking the operating system thread, the coroutine yields an intermediate Future instance upwards to the scheduler step function.

Observe the lifecycle below: the task explicitly unregisters its active execution state and registers an epoll or select callback with the event loop kernel before yielding CPU control back to the central dispatch queue.

code cpython/Lib/asyncio/tasks.py — __step() internals Python 3.12 
# 1. Coroutine suspension protocol invocation
def _step(self, exc=None):
    coro = self._coro
    try:
        # Advance coroutine to next yield point
        result = coro.send(None) if exc is None else coro.throw(exc)
    except StopIteration as exc:
        self.set_result(exc.value)
    else:
        # Awaitable returned: wire wake-up callback to loop
        if isinstance(result, Future):
            result.add_done_callback(self._wakeup, context=self._context)
        else:
            self._loop.call_soon(self._step)
