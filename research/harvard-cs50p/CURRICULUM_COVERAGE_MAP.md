# Curriculum Coverage Map: Harvard CS50P vs. CERTIFY Python Fundamentals

This document maps high-level topics from [Harvard CS50P](https://cs50.harvard.edu/python/) to CERTIFY's independently authored 10-module *Python Fundamentals* curriculum. It is a **structural comparison** for curriculum engineering—not a reproduction of CS50P content.

## 2. Structural Sequence Adjustments (Documented Rationale)

1. **Foundations First, Functions Deepened in Module 04:** While CS50P introduces `def` in Week 0, CERTIFY introduces *calling* built-in functions and core collections in Module 01, then dedicates **Module 02 (Decision Making)** and **Module 03 (Iteration)** before **Module 04 (Functions & Modular Programming)**. This prevents absolute beginners from juggling indentation, control flow, and lexical scope simultaneously, while still introducing modular decomposition before Exceptions, Libraries, and Unit Testing.
2. **All Four Core Collections Introduced Early (Module 01):** Unlike CS50P (which delays `tuple` to Week 8 and `set` to Week 9), CERTIFY introduces `list`, `tuple`, `dict`, and `set` side-by-side in Module 01 so learners build an accurate mutability/hashability mental model early.
3. **Extension Topics Placed by Prerequisite Fit:**
   - *Mutability & shallow/deep copy* → Module 01 (and reinforced in Module 04).
   - *Unpacking, `enumerate`, `zip`, list/dict comprehensions* → Module 03.
   - *Type hints & docstrings* → Module 04 (and reinforced in Module 07).
   - *Command-line arguments (`sys.argv`, `argparse`)* → Module 06.
   - *Iterators, generators, `yield`* → Module 08 (paired with file streaming).
