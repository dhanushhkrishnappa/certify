# Harvard CS50P Reference Notes

Concise, factual research notes with verified official URLs supporting curriculum observations. **No lecture transcripts, slides, notes, or problem statements are stored here.**

---

- **Course Portal ([https://cs50.harvard.edu/python/](https://cs50.harvard.edu/python/)):**
  - 10-week OpenCourseWare Python course taught by David J. Malan.
  - Explicitly designed for learners with or without prior programming experience.
  - Recommended student workflow per week: Watch Lecture → Watch Shorts → Submit Problem Set → Final Project.

- **Week 0 – Functions, Variables ([https://cs50.harvard.edu/python/weeks/0/](https://cs50.harvard.edu/python/weeks/0/)):**
  - Lecture (~1h 45m) covers CLI, Python interpreter, `print`, arguments, side effects, bugs, return values, variables, comments, pseudocode, `str`, string methods, `split`, `int`, `float`, numeric formatting, `def`, scope, `return`.
  - Resources provided: Audio (MP3), Notes, Slides (Google Slides/PDF), Source Code (Index/PDF/Zip), Subtitles, Transcript, Video, Shorts (VS Code, Functions, Variables, Return Values, Side Effects), Problem Set 0.
- **Week 1 – Conditionals ([https://cs50.harvard.edu/python/weeks/1/](https://cs50.harvard.edu/python/weeks/1/)):**
  - Lecture (~56m) covers `if`, `elif`, `else`, `or`, `!=`, indentation/colons, `and`, chained comparisons, modulo, `bool`, Pythonic expressions, `match`.
  - Shorts: Conditionals, Boolean Expressions. Problem Set 1.
- **Week 2 – Loops ([https://cs50.harvard.edu/python/weeks/2/](https://cs50.harvard.edu/python/weeks/2/)):**
  - Lecture (~1h 20m) covers `while`, `for`, input validation, iteration with lists, `len`, `dict`, lists of dicts, nested loops.
  - Shorts: Dictionaries, Dictionary Methods, For Loops, Lists, List and Dictionary Comprehensions, List Methods, String Methods, String Slicing, Tuples, While Loops. Problem Set 2.
- **Week 3 – Exceptions ([https://cs50.harvard.edu/python/weeks/3/](https://cs50.harvard.edu/python/weeks/3/)):**
  - Lecture (~44m) covers `SyntaxError`, `ValueError`, `try`/`except`, `NameError`, `else`, reprompting/`break`, `get_int` helper, `pass`, `raise`.
  - Shorts: Debugging, Handling Exceptions, Raising Exceptions. Problem Set 3.
- **Week 4 – Libraries ([https://cs50.harvard.edu/python/weeks/4/](https://cs50.harvard.edu/python/weeks/4/)):**
  - Lecture (~1h 10m) covers modules, `import`, `from`, `random` (`randint`, `shuffle`), `statistics`, `sys.argv`, `sys.exit`, slices, PyPI/`pip`, `cowsay`, APIs/`requests`/JSON, custom libraries (`__name__`).
  - Shorts: API Calls, Creating Modules and Packages, `random`, Style. Problem Set 4.
- **Week 5 – Unit Tests ([https://cs50.harvard.edu/python/weeks/5/](https://cs50.harvard.edu/python/weeks/5/)):**
  - Lecture (~50m) covers unit tests, `assert`, `AssertionError`, `pytest`, categories of tests, testing for exceptions, side effects vs testing, collections of tests (`__init__.py`).
  - Shorts: `pytest`. Problem Set 5.
- **Week 6 – File I/O ([https://cs50.harvard.edu/python/weeks/6/](https://cs50.harvard.edu/python/weeks/6/)):**
  - Lecture (~1h 32m) covers `open`, `with`, `sorted`, sort keys, `lambda`, CSV (`csv.reader`, `DictReader`, `writer`, `DictWriter`), images/PIL.
  - Shorts: Pillow, Reading and Writing CSVs, Reading and Writing Files. Problem Set 6.
- **Week 7 – Regular Expressions ([https://cs50.harvard.edu/python/weeks/7/](https://cs50.harvard.edu/python/weeks/7/)):**
  - Lecture (~2h 04m) covers validation without regex, `re` library, patterns, start/end anchors, character sets/classes, flags, groups & capturing, `match`/`fullmatch`, walrus operator (`:=`), `re.sub`, `re.search`.
  - Shorts: Patterns, Capture Groups. Problem Set 7.
- **Week 8 – Object-Oriented Programming ([https://cs50.harvard.edu/python/weeks/8/](https://cs50.harvard.edu/python/weeks/8/)):**
  - Lecture (~2h 32m) covers tuples/dicts vs classes, objects, instance methods, attribute validation, `__str__`, custom methods, `@property` getters/setters, `@classmethod`, `@staticmethod`, inheritance, operator overloading (`__add__`).
  - Shorts: Classes, Class Methods and Class Variables, Instance Variables, Instance Methods. Problem Set 8.
- **Week 9 – Et Cetera ([https://cs50.harvard.edu/python/weeks/9/](https://cs50.harvard.edu/python/weeks/9/)):**
  - Lecture (~2h 23m) covers `set`, `global`, constants, type hints & `mypy`, docstrings, `argparse`, unpacking (`*args`, `**kwargs`), `map`, `filter`, list/dict comprehensions, `enumerate`, generators, iterators, `yield`.
  - Shorts: Recursion, Final Project.
- **Final Project ([https://cs50.harvard.edu/python/project/](https://cs50.harvard.edu/python/project/)):**
  - Requires `project.py` with `main()` + at least 3 top-level custom functions, `test_project.py` with `pytest` tests for those 3+ functions, `requirements.txt`, ~500-word `README.md`, and a <=3-minute demo video.
