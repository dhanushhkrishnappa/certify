# Module 04 – Functions and Modular Programming

## Module Description
Functions package reusable logic with clear inputs (parameters) and outputs (`return`). This module covers `def`, positional/keyword/default arguments, `*args`/`**kwargs`, LEGB scope, the mutable default argument trap, recursion, modular decomposition, **type hints**, and **docstrings**.

## Why This Module Matters
Without functions, programs become tangled monoliths. Functions let you test behavior in isolation (Module 07), avoid duplicate code, and reason about local vs. global state.
