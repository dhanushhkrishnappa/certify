# Module 04 – Learning Objectives

1. **Design** pure functions with explicit parameters, `return` values, type hints, and PEP 257 docstrings.
2. **Trace** Python's LEGB scope resolution and explain why `global` is discouraged.
3. **Avoid** the mutable default argument trap by using `None` sentinels.
4. **Implement** simple recursive functions with clear base and recursive cases.
