# Module 03 – Exercises

1. **Guided – Positive Sum (`ex_m03_1`):** Sum only positive numbers in `[3, -2, 7, 0, -4, 5]` using `continue`.
2. **Independent – Parallel Pairing (`ex_m03_2`):** Given `items = ['pen', 'book']` and `prices = [1.5, 12.0]`, build a dict `{item: price}` with a dict comprehension + `zip()`.
3. **Independent – Comprehension Filter (`ex_m03_3`):** Create a list of squares of odd numbers from `1` to `15`.
