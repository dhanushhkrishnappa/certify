# Module 03 – Learning Objectives

1. **Choose** `while` for condition-driven repetition and `for` for sequence/iterable traversal.
2. **Trace** `range(start, stop, step)`, `break`, `continue`, and nested loops step by step.
3. **Implement** accumulation (sum, count, min/max) and searching patterns cleanly.
4. **Apply** tuple unpacking, `enumerate()`, `zip()`, and list/dictionary comprehensions idiomatically.
