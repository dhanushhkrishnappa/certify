# Module 01 – Learning Objectives

1. **Explain** how the Python interpreter executes statements top-to-bottom and enforces indentation blocks.
2. **Trace** variable assignments as object references in memory, distinguishing rebinding from mutation.
3. **Apply** explicit type conversion (`int()`, `float()`, `str()`) when combining `input()` with arithmetic.
4. **Format** dynamic text using f-strings and core string methods (`.strip()`, `.lower()`, `.split()`).
5. **Choose** between `list`, `tuple`, `dict`, and `set` based on ordering, mutability, and uniqueness needs.
6. **Prevent** aliasing bugs using `.copy()` and `copy.deepcopy()`.
