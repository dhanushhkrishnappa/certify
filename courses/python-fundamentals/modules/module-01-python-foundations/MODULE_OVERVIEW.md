# Module 01 – Python Foundations

## Module Description
This module builds your foundational mental model of how Python runs code, stores values in memory, processes text and numbers, interacts with users, and organizes data in core collections (`list`, `tuple`, `dict`, `set`).

## Why This Module Matters
Beginners often memorize syntax without understanding what Python actually does in memory. By learning early that variables are *labels attached to objects*—and that some objects can change in place while others cannot—you avoid the most common bugs in Python.

## Previous Knowledge Required
None. This module is designed for absolute beginners.

## Estimated Learning Time
4.5 hours (reading, interactive tracing, and hands-on exercises).

## Concepts Included
1. Python installation, REPL vs. script execution, syntax, indentation, comments, and basic debugging.
2. Variables, object references, mutability vs. immutability, shallow vs. deep copying.
3. Primitive data types (`int`, `float`, `str`, `bool`), type conversion, operators, strings, and `input()`/`print()`.
4. Core collections (`list`, `tuple`, `dict`, `set`).

## Real-World Applications
- Writing quick automation scripts and interactive CLI utilities.
- Parsing user-entered text, formatting reports with f-strings, and storing structured records.

## Learning Outcomes & Skills to Master
- Run Python in interactive mode and via `.py` files.
- Trace variable rebinding vs. in-place mutation using `id()`.
- Convert types safely, format output, and select the right collection type for a task.
