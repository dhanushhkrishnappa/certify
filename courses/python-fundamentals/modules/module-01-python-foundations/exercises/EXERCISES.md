# Module 01 – Exercises

1. **Guided – Time Splitter (`ex_m01_1`):** Given `total_seconds = 3675`, compute `hours`, `minutes`, and `seconds` using `//` and `%`, and print `1h 1m 15s`.
2. **Guided – Safe Profile Clone (`ex_m01_2`):** Create `template = {"role": "learner", "badges": ["welcome"]}`. Clone it with `copy.deepcopy`, add `"python-1"` to the clone's `"badges"`, and assert `template["badges"]` still has length 1.
3. **Independent – Tag Deduplicator (`ex_m01_3`):** Given `raw_tags = [" python ", "AI", "python", "ai "]`, normalize each to lowercase stripped strings, deduplicate with a `set`, and print a sorted `list`.
