# Module 08 – File Handling and Data Processing

## Module Description
Data in memory disappears when a program exits. This module covers persistent file handling (`pathlib.Path`, `open()`, `r`/`w`/`a` modes, `with` context managers), structured formats (`csv` and `json`), file exceptions, and **iterators, generators, and `yield`** for memory-efficient stream processing.

## Previous Knowledge Required
Modules 01–07.

## Estimated Learning Time
4.5 hours.
