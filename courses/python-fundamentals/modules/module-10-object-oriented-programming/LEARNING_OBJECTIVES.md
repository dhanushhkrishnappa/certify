# Module 10 – Learning Objectives

1. **Model** real-world domain entities as Python classes with validated `__init__` state.
2. **Distinguish** instance attributes from class attributes and protect invariants with `@property`.
3. **Choose** between composition ("has-a") and inheritance ("is-a") with `super()`.
4. **Implement** `__str__`, `__repr__`, and `__eq__` for clean debugging and equality semantics.
