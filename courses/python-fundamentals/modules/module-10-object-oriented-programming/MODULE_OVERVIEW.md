# Module 10 – Object-Oriented Programming

## Module Description
Object-Oriented Programming (OOP) bundles data (attributes) and behavior (methods) into cohesive blueprints called **classes**. This capstone module covers procedural vs. OOP trade-offs, classes and objects, `__init__`, `self`, instance vs. class variables, `@property` validation, encapsulation, inheritance (`super()`, method overriding), composition, and special methods (`__str__`, `__repr__`, `__eq__`).

## Previous Knowledge Required
Modules 01–09 (especially Functions, Exceptions, and Unit Testing).

## Estimated Learning Time
5.5 hours.
