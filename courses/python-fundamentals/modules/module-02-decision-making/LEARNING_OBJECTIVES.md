# Module 02 – Learning Objectives

1. **Construct** compound boolean conditions using `and`, `or`, `not`, and chained comparisons (`0 <= x <= 100`).
2. **Design** mutually exclusive `if`/`elif`/`else` ladders without shadowed branches.
3. **Predict** the exact return value of short-circuit expressions like `'a' and '' or 'fallback'`.
4. **Distinguish** `==` (value equality) from `is` (object identity, reserved for `None`).
