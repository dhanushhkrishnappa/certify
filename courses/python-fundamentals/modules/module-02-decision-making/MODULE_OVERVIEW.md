# Module 02 – Decision Making

## Module Description
Programs become intelligent when they choose different paths based on data. This module covers boolean expressions, comparison and logical operators, `if`/`elif`/`else`, conditional expressions, truthiness, short-circuit evaluation, and `is` vs `==`.

## Why This Module Matters
Most subtle logic bugs happen in conditions—unreachable `elif` branches, `x == 1 or 2` always evaluating truthy, or confusing `==` (value equality) with `is` (object identity).

[Module 01 – Python Foundations](../module-01-python-foundations/MODULE_OVERVIEW.md).

## Estimated Learning Time
3.5 hours.

## Concepts Included
1. Boolean expressions, comparison operators, logical operators (`and`, `or`, `not`).
2. `if`, `elif`, `else`, nested conditions, conditional expressions (`a if cond else b`).
3. Truthiness and short-circuit evaluation.
4. `is` vs `==` and common logical errors.
