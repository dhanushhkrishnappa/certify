# Module 07 – Unit Testing and Code Quality

## Module Description
Manually re-running scripts after every edit doesn't scale. This module teaches `assert`, `AssertionError`, `pytest`, testing edge cases and exceptions, organizing test suites, Test-Driven Development (TDD) basics, PEP 8 naming conventions, and documentation.

## Previous Knowledge Required
Modules 04–06.

## Estimated Learning Time
3.5 hours.
