# Module 09 – Regular Expressions

## Module Description
Regular expressions (`re`) describe text patterns concisely for validation, extraction, and transformation. This module covers raw strings, character classes, quantifiers, anchors, capturing groups, `re.search`/`match`/`fullmatch`/`findall`/`sub`, and knowing when simpler `str` methods are better.
