# Module 09 – Learning Objectives

1. **Author** readable regex patterns using raw strings (`r"..."`).
2. **Validate** entire strings cleanly with `re.fullmatch()` or `^...$` anchors.
3. **Extract** structured fields with capturing groups and transform text with `re.sub()`.
4. **Decide** when `str` methods (`.startswith()`, `.split()`) are cleaner than regex.
