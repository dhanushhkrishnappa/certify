# CERTIFY – Python Fundamentals

**Course Slug:** `python-fundamentals`  
**Version:** `2.0.0` (10-Module RAG & BKT Edition)  
**Target Audience:** Absolute beginners, first-time Python learners, students preparing for programming assessments, and learners seeking genuine conceptual mastery over syntax memorization.  
**Estimated Duration:** ~42 Hours across 10 Modules

---

## Teaching Philosophy

1. **Intuition before syntax:** Every concept begins with *why it exists* and *what problem it solves*.
2. **Conceptual understanding before complex examples:** Learners build accurate mental models of Python's execution and memory behavior.
3. **Visualisation before abstraction:** Object references, call stacks, and data flow are traced step-by-step.
4. **Simple examples before real-world applications:** Minimal runnable scripts precede multi-step workflows.
5. **Guided practice before independent problem solving:** Scaffolded exercises bridge reading and unassisted coding.
6. **Debugging and reasoning throughout:** Errors and tracebacks are treated as diagnostic tools, not roadblocks.
7. **Assessment of actual understanding:** Non-MCQ conceptual probes, practical code tests, and oral viva defenses align directly with CERTIFY's Bayesian Knowledge Tracing (BKT) engine.

## Module Roadmap & Extension Integration

| Module | Title | Core Focus | Integrated Extension Topics |
| :--- | :--- | :--- | :--- |
| **01** | Python Foundations | Execution, variables, types, operators, strings, I/O, core collections | Mutability vs. immutability, object references, shallow vs. deep copy |
| **02** | Decision Making | Booleans, comparisons, `if`/`elif`/`else`, `match`, truthiness | Short-circuit return values, `is` vs. `==` |
| **03** | Iteration and Problem Solving | `while`, `for`, `range`, `break`/`continue`, nested loops, patterns | Unpacking, `enumerate`, `zip`, list & dict comprehensions |
| **04** | Functions and Modular Programming | `def`, parameters, `return`, scope (LEGB), recursion, decomposition | Type hints, docstrings (PEP 257), `*args`/`**kwargs` |
| **05** | Exceptions and Debugging | Error taxonomy, tracebacks, `try`/`except`/`else`/`finally`, `raise` | Defensive validation, systematic debugging |
| **06** | Libraries and Python Ecosystem | Modules, `import`, stdlib (`random`, `statistics`, `math`, `datetime`), `pip`, `venv` | Command-line arguments (`sys.argv`, `argparse`) |
| **07** | Unit Testing and Code Quality | Assertions, `pytest`, edge cases, TDD basics, readability | PEP 8 naming & documentation standards |
| **08** | File Handling and Data Processing | Paths, `open`, `with`, CSV, JSON, file exceptions | Iterators, generators, `yield` for lazy streaming |
| **09** | Regular Expressions | Patterns, raw strings, classes, quantifiers, anchors, groups, `re` | Choosing `str` methods vs. regex responsibly |
| **10** | Object-Oriented Programming | Classes, objects, `__init__`, properties, inheritance, composition, dunders | Practical domain modeling & encapsulation |
